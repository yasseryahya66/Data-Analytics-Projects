## Projects

### 1. Vehicle Sales Data Cleaning & Market Analysis

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn

- Cleaned and prepared a 3.5 million-record vehicle listings dataset.
- Handled missing values using median, mode, and group-based imputation techniques.
- Detected and treated outliers using the IQR method.
- Analyzed vehicle prices, mileage, engine specifications, fuel types, and manufacturer trends.
- Created visualizations to identify market patterns and trends.

### 2. Cafe Sales Data Cleaning & Exploratory Data Analysis

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn

- Processed and cleaned 10,000+ cafe transaction records.
- Improved data quality through missing-value treatment and data type correction.
- Analyzed revenue trends, product performance, payment methods, and transaction locations.
- Created visual reports to support business insights.

---

### 3. Retail Sales Data Cleaning & Exploratory Data Analysis

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn

- Cleaned and analyzed 12K+ retail transaction records.
- Performed data preprocessing, duplicate validation, feature engineering, and data standardization.
- Created time-based features to analyze seasonal sales patterns.
- Identified top-performing categories, customer trends, and revenue drivers.
