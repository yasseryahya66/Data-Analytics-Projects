## Projects

### 1. Vehicle Sales Data Cleaning & Market Analysis

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn

- Cleaned and prepared a 3.5 million-record vehicle listings dataset.
- Handled missing values using median, mode, and group-based imputation techniques.
- Validated categorical and numerical fields to improve data quality.
- Detected and treated outliers using the Interquartile Range (IQR) method.
- Performed exploratory data analysis on vehicle prices, mileage, engine specifications, fuel types, and manufacturer trends.
- Created visualizations to identify market patterns and support data-driven insights.

### 3. Retail Sales Data Cleaning & Exploratory Data Analysis

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn**

- Cleaned and analyzed a retail transaction dataset containing 12K+ sales records.
- Performed data preprocessing including column standardization, duplicate validation, missing-value treatment, and data type conversion.
- Applied logic-based imputation techniques by reconstructing missing sales information using relationships between price, quantity, and total spending.
- Performed feature engineering by extracting time-based features such as year, quarter, month, and weekday from transaction dates.
- Analyzed sales performance across product categories, payment methods, customer segments, and locations.
- Identified top-performing categories, revenue trends, customer purchasing patterns, and relationships between quantity, unit price, and total sales.
- Created analytical visualizations including revenue trend charts, distribution plots, correlation heatmaps, and comparative analysis graphs to support business insights.

### 4. Employee Performance Analysis & HR Analytics

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn

- Cleaned and analyzed a 17K+ employee records dataset to understand workforce characteristics and performance patterns.
- Removed duplicate records and improved dataset quality through missing-value handling and data type optimization.
- Applied appropriate imputation techniques:
  - Replaced missing education values with an "Unknown" category.
  - Filled missing performance ratings using median imputation.
- Conducted exploratory data analysis on employee demographics, departments, education levels, recruitment channels, training performance, and years of service.
- Analyzed relationships between employee ratings, KPI achievement, training scores, and career experience.
- Created visualizations including distribution plots, boxplots, correlation heatmaps, and categorical comparisons.
- Identified patterns related to employee performance, recruitment sources, and workforce structure.
- Applied feature engineering by creating employee experience categories (Junior, Mid, Senior, Veteran) based on length of service.
- Generated HR insights to understand factors influencing employee performance and organizational trends.
